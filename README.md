# APD – Laborator 

Proiect de laborator pentru disciplina Achiziția și prelucrarea datelor. Nod de achiziție a temperaturii bazat pe Arduino Uno.

# Hardware

Arduino Uno R3, senzor de temperatură TMP36


## Senzori utilizați
| Senzor | Interfață | Domeniu |
|---|---|---|
| TMP36 | Analogic (A0) | -40°C .. +125°C |
